# ProjectHLN UI System v4 — Parent-Owned Interface Contract

> **Authority.** This file is the single shared interface contract for the v4
> engine. Every implementation module (tokens, themes, base, folio layout,
> runtime, build, tests, workbench) MUST match the identifiers, token names,
> DOM attribute contract, class names and values pinned here. If an
> implementation module needs a value that is not pinned here, it must NOT
> invent one — it must use the token/attribute/class already pinned, or leave
> the value to the token system.

## 0. What v4 is

**v4.0 "Folio" — Calm Minimal Multi-Pigment Edition.**

A framework-neutral visual foundation for ProjectHLN clients, shipped as an
independent package in `ui-source/v4/`.

### 0.1 How v4 differs from the three prior generations (design intent, not decoration)

| Generation | Metaphor | Canvas | Geometry | Colour model | Ornament |
|---|---|---|---|---|---|
| v1 | Foundational Multiverse | dark + aurora | 8–16px round, translucent | one accent per theme | blobs, blur fields |
| v2 / v2.3 | HyperGryph Tactical | near-black | 0px chamfer, brackets | one accent per theme | hazard hatch, scanlines |
| v3.x | Euclidean / Cosmic observatory | near-black | 0–4px, fiducials | one hue per theme | grids, reticles, telemetry |

**v4 breaks all four axes at once:**

1. **Light-first.** v4 is the first engine in this repository whose *default*
   canvas is a warm paper tone rather than near-black. Four of eight themes are
   light; the dark themes are desaturated and lifted (`#16181b` … `#111418`),
   never `#000`.
2. **Soft geometry.** 4 / 6 / 8px radii are the whole vocabulary. No chamfer,
   no notch, no corner fiducial, no bezel.
3. **Two real pigments per theme.** Every theme carries a *primary* pigment
   (`--hln-ui-accent`) and a *secondary* pigment (`--hln-ui-accent-cool`) from
   a different hue family. Prior generations varied one hue; v4 varies a
   **pigment pair**, so a theme reads as a place with its own colour logic.
4. **Static surfaces.** Ambient background presets are static gradients and
   patterns. No repeating pulse, scan, shimmer, drift, or symbol-stream effect
   appears anywhere in v4. Motion is one-shot and limited to opacity +
   transform, per the shared contract.

### 0.2 Signature elements (spend the boldness in exactly two places)

- **The Wash** (primary signature) — the selected / active state of a control
  is a *pigment wash*, not a flat fill: `background` tinted with the accent at
  ~10%, a **2px solid accent bar on the leading edge**, and the label colour
  switched to the accent. It reads like a highlighter stroke over a line of
  text, not like a lit-up button.
- **The Running Head** (supporting frame) — every panel opens with a mono,
  uppercase, wide-tracked eyebrow (`SPECIFICATION`, `COMPOSER`, `READOUT`)
  above its title, followed by a hairline that runs to the panel edge. It is
  the only place where mono uppercase text is used as a structural device.

Everything else stays quiet: no glows, no notches, no bezel, no decorative
telemetry, no gradients except the single accent wash.

## 3. DOM contract (inherited from `ui-source/contract.md` — non-negotiable)

```text
[data-hln-ui-root]
  [data-hln-ui-bar]*
  [data-hln-ui-surface="glass"|"panel"|"glass-strong"|"quiet"]*
  [data-hln-ui-scroll]*
  [data-hln-ui-resize-handle="vertical"|"horizontal"]*
  [data-hln-ui-control]*
  [data-hln-ui-field]*
```

Rules v4 must honour:

- Every `[data-hln-ui-control]` exposes an accessible name (`aria-label`,
  `aria-labelledby`, or visible text) and marks selection with
  `data-active="true"`.
- Radii for ordinary controls and panels are **≤ 8px**. Status chips may use
  the pill radius (`--hln-ui-radius-pill`). No other element may exceed 8px.
- `[data-hln-ui-field]` is a form field; it must show a visible focus ring.
- Scroll regions use the custom scrollbar contract, never the browser default.
- `[data-hln-ui-resize-handle]` exposes a 14px hit target; the visible rule is
  drawn by the shared layer.
- No horizontal overflow at 320px.
- `prefers-reduced-motion: reduce` disables all animation and transition.

**Contrast contract.** Every text tier a theme defines MUST clear **WCAG AA
(4.5:1)** against every surface it can land on — `bg-0`, `bg-1`, `bg-2`, the

both assert this.

```css
[data-hln-ui-root][data-hln-ui-version="v4"] { ... }
```

Sets `background-color: var(--hln-ui-bg-0)`, `color: var(--hln-ui-text)`,

`line-height: 1.6`, `-webkit-font-smoothing: antialiased`,
`text-rendering: optimizeLegibility`.

### 5.2 Surfaces

```css
[data-hln-ui-surface]            /* base surface: bg-1, 1px line, radius-lg 8px, shadow-sm */
[data-hln-ui-surface="panel"]    /* default panel */
[data-hln-ui-surface="glass"]    /* translucent panel-bg + backdrop-filter blur(var(--hln-ui-blur)) */
[data-hln-ui-surface="glass-strong"] /* glass + stronger shadow */
[data-hln-ui-surface="quiet"]    /* no shadow, no border, transparent bg */
```

### 5.3 Controls

```css
[data-hln-ui-control]
```

- `min-height: var(--hln-ui-control-height)`, `padding: 0 12px`
- `border: 1px solid var(--hln-ui-line)`, `border-radius: var(--hln-ui-radius-sm)`
- `background: var(--hln-ui-bg-2)`, `color: var(--hln-ui-text)`
- `font-size: 13px`, `font-weight: 500`, `letter-spacing: 0.01em`
- `transition: background-color 140ms, border-color 140ms, color 140ms`
- `:hover` → border `var(--hln-ui-line-strong)`, background
  `color-mix(in srgb, var(--hln-ui-text) 5%, var(--hln-ui-bg-2))`
- `:focus-visible` → `outline: 2px solid var(--hln-ui-focus)`,
  `outline-offset: 2px`

**The engine owns its focus ring.** The rule above is also shipped in a
version-scoped form —
`[data-hln-ui-root][data-hln-ui-version="v4"] [data-hln-ui-control]:focus-visible`
— because a host chrome rule such as
`.shell :is(button, input, [tabindex]):focus-visible` scores (0,2,1), out-specifies
the unscoped (0,2,0) rule and repaints the ring with `currentColor`. On a solid
accent fill `currentColor` is the on-accent text, i.e. the same colour as the
page: the ring disappears exactly where the user most needs it. The version-scoped
selector restores the token without reaching into another engine's controls.

Every focus indicator the engine paints MUST clear **3:1** against the surface it
sits on (WCAG 1.4.11 non-text contrast). One control cannot use an outline:
`.hln-v4-composer` clips overflow, so an outline drawn outside the textarea is cut
away entirely. The composer's indicator is therefore an **inset** ring —
`box-shadow: inset 0 0 0 2px var(--hln-ui-focus)` — and it is solid rather than a
wash, because a 26% accent wash measures only 1.54:1 against the paper.
- `[data-active="true"]` → **the Wash**:
  `border-color: var(--hln-ui-accent)`,
  `background: color-mix(in srgb, var(--hln-ui-accent) 10%, var(--hln-ui-bg-2))`,
  `color: var(--hln-ui-accent)`
- `[data-variant="accent"]` → solid accent fill, `color: var(--hln-ui-bg-0)`,
  `border-color: var(--hln-ui-accent)`
- `[data-variant="ghost"]` → transparent background, no border until hover
- `[data-variant="quiet"]` → no border, muted text
- `[data-variant="danger"]` → accent is the danger colour

### 5.8 Motion

Presets: `[data-hln-motion="panel"]`, `="item"`, `="control"`.
Enter state selector: `[data-hln-motion-state="enter"]` plus optional
`[data-hln-motion-variant="<variant>"]`.

Variants (all **one-shot**, **opacity + transform only**, ≤ 300ms):

| variant | keyframes |
|---|---|
| `rise` | opacity 0→1, translateY(10px)→0 |
| `unfold` | opacity 0→1, translateY(6px) scale(0.985)→1 |
| `spring` | opacity 0→1, translateY(12px)→0, `--hln-ui-ease-spring` |
| `slide-left` | opacity 0→1, translateX(-12px)→0 |
| `slide-right` | opacity 0→1, translateX(12px)→0 |
| `type-in` | opacity 0→1, translateY(4px)→0 |
| `page-shift` | opacity 0→1, translateX(16px)→0 |

Stagger: `animation-delay: calc(var(--hln-ui-motion-index, 0) * var(--hln-ui-motion-stagger))`.

`@media (prefers-reduced-motion: reduce)` must disable animation and
transition for the whole v4 root.

**No `animation-iteration-count: infinite` anywhere in v4.**

### 5.9 Ambient background presets (`data-hln-bg-motion`)

All **static** (no animation, no transition). Implement on
`[data-hln-ui-root][data-hln-bg-motion="<id>"]::before` with
`position:absolute; inset:0; z-index:0; pointer-events:none;` and on
`> :not(.hln-stochastic-canvas) { position: relative; z-index: 1; }`.

| id | label | description |
|---|---|---|
| `paper-grain` | Paper Grain | very fine warm grain via repeating conic/radial dots |
| `margin-rule` | Margin Rule | a single vertical hairline at 12% + a horizontal rule at 78% |
| `tint-wash` | Tint Wash | one broad radial wash of `--hln-ui-accent` at ~7% in the top-left |
| `ruled-lines` | Ruled Lines | 32px horizontal hairlines at 5% |
| `folio-grid` | Folio Grid | 40px baseline grid at 4% |
| `vellum-fiber` | Vellum Fiber | soft vertical fiber streaks at 4% |
| `quiet` | Quiet | no ornament at all |

### 6.3 Skin allowlist

`createHlnSkin()` accepts `{ id, tokens }` where `id` matches
`/^[a-z0-9][a-z0-9-]{1,40}$/` and `tokens` is an object whose keys are drawn
**only** from this allowlist:

```js
["--hln-ui-accent", "--hln-ui-accent-cool", "--hln-ui-on-accent", "--hln-ui-bg-0",
 "--hln-ui-bg-1", "--hln-ui-bg-2", "--hln-ui-panel-bg", "--hln-ui-text", "--hln-ui-text-muted",
 "--hln-ui-text-faint", "--hln-ui-line", "--hln-ui-line-strong", "--hln-ui-focus",
 "--hln-ui-success", "--hln-ui-warning", "--hln-ui-danger"]
```

Values must be valid CSS colours (`#rgb`, `#rrggbb`, `#rrggbbaa`, `rgb()`,
`rgba()`, `hsl()`, `hsla()`, or a `var(...)` reference). Invalid input throws
`TypeError`. `applyHlnSkin()` writes only the allowlisted tokens onto the host
root's inline style and returns a cleanup function that restores the previous
inline values.

`--hln-ui-on-accent` is allowlisted because it is the counterpart of
`--hln-ui-accent`: a skin that replaces the accent **MUST** replace the
on-accent text colour with one that still clears **4.5:1** against the new
accent, or text on solid accent fills becomes unreadable. The engine cannot
repair this automatically — the engine is CSS-first and never computes a
replacement colour at runtime.

### 6.4 `playHlnMotion(scope, preset, variant)`

- `scope` may be an element or a root.
- Applies `data-hln-motion-state="enter"` and `data-hln-motion-variant` to the
  scope and/or its `[data-hln-motion="<preset>"]` descendants.
- Sets `--hln-ui-motion-index` per element index for staggering.
- Returns the number of elements animated.
- Must be a no-op under `prefers-reduced-motion: reduce`.

### 6.5 `hlnFlip(element)`

- Applies a bounded transform transition (150–300ms, transform + opacity only)
  to the element, then removes it after the transition ends.
- Must be a no-op under `prefers-reduced-motion: reduce`.

## 11. Content voice

The shared contract's interface-voice rules apply to every string written into
the v4 showcase:

- Active voice, plain verbs, sentence case for UI labels.
- The action keeps the same name through the flow ("保存" → "已保存").
- Errors state what happened and what to do; they never apologise.
- Empty states invite an action.
- Technical identifiers (token names, ids, versions) stay in the mono face.
