# ProjectHLN UI System v3.2 Contract — Subtractive Linear Architecture

## 1. Design Philosophy
`v3.2` performs deliberate aesthetic subtraction on `v3` (Mathematical Vector Proportions) and `v2` (Minimalist High-Contrast Atmosphere):
- **Open Linear Architecture**: Replaces enclosed multi-box cards, polygon `clip-path` cuts, and corner L-brackets with continuous `1px` structural hairlines (`--hln-v32-rule`), open negative space, and grand typographic hierarchy.
- **Zero Blur & Zero Offset Shadow**: Enforces `--hln-ui-blur: 0px` and `--hln-ui-shadow: none` across all 6 themes.
- **Zero Game Terminology**: Contains purely mathematical, linear, and architectural nomenclature.
